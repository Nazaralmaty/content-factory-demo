# ULTRA REEL

Рилс, где речь, картинка и музыка — одна композиция. Не «видео + фоновый трек + субтитры»,
а партитура: каждое значимое слово получает визуальное событие, каждое визуальное событие —
звук, а музыка дышит в паузах речи и замолкает там, где спикер говорит главное.

Рабочие файлы: `scripts/engine/` (DSP, синтез, сведение, графика на Skia), `scripts/*.py`
(анализ, QA), `scripts/template/` — полный рабочий проект (отзыв для агентства ICON, 44.6 с),
который копируется и переделывается под новый исходник. Подробности — в `references/`.

## 0. Исходник и ограничения

Выясни из запроса (не переспрашивай, если ясно из контекста):
- **Резать или нет.** По умолчанию речь НЕ режется: таймлайн речи неприкосновенен, вся
  музыка и графика строится вокруг него. Джамп-каты по паузам — только по явной просьбе.
- **Цель ролика**: отзыв / оффер / экспертиза → от этого зависит хук и финальная плашка.
- **Язык титров** = язык речи. Бренды и имена пиши так, как их слышно, и вынеси все
  сомнительные написания в финальный отчёт пользователю.
- **Факты**: на экране только то, что сказано, или честный пересказ. Не придумывай цифры,
  рейтинги, звёзды, «основатель» и т.п., если этого нет в речи.

## 1. Окружение (5–10 минут, один раз за сессию)

```bash
SK=<путь к этому скиллу>; WORK=<рабочая папка ролика>
bash $SK/scripts/setup.sh          # pip: faster-whisper numba skia-python scipy soundfile pyloudnorm ...
                                   # apt: libegl1 (нужен skia); шрифты → ~/.cache/ultra-reel/fonts
bash $SK/scripts/fetch_whisper.sh  # faster-whisper large-v3 → ~/.cache/ultra-reel/whisper-large-v3;
                                   # если HuggingFace закрыт — достаёт модель из слоя Docker-образа
export ULTRA_ENGINE=$SK/scripts REEL_FONTS=~/.cache/ultra-reel/fonts MODEL=~/.cache/ultra-reel/whisper-large-v3
```

## 2. Анализ исходника

```bash
python3 $SK/scripts/prep_media.py SRC.mp4 $WORK        # voice16k/48k.wav, speaker.npy (грейд+шарп), media.json (AV-offset, кружок?)
python3 $SK/scripts/transcribe.py $WORK/voice16k.wav $MODEL $WORK/words_asr.json
python3 $SK/scripts/align.py $WORK/voice48k.wav $WORK/words_asr.json $WORK/words_aligned.json
python3 $SK/scripts/probe_clips.py $WORK/voice16k.wav $MODEL '[[6.4,10.3],[39.7,41.6]]'  # перепроверка спорных мест
python3 $SK/scripts/make_words.py $WORK/words_aligned.json $WORK/media.json $WORK/words.json \
        '{"17":[6.02,6.44],"21":[8.67,9.70,"Еркебулан"],"22":null}'                   # ручные правки по индексам
python3 $SK/scripts/analyze_voice.py $WORK/voice48k.wav $WORK   # F0 → тональность, паузы; пишет f0.npz
cp $SK/scripts/template/{plan,score,render}.py $WORK/            # шаблон-проект рядом с данными
```

- Whisper ошибается в таймингах на именах и паузах до 0.5 с. `align.py` сопоставляет гласные
  транскрипта с энергетическими пиками (каждый слог = одна гласная) — это лечит большинство
  сдвигов. Ключевые слова (бренд, имена, слово-дроп, последнее слово) **перепроверь**
  `probe_clips.py` и при необходимости зафиксируй вручную в `words.json`.
- Учти **AV-offset**: у аудиодорожки бывает `start_time` > 0 (у кружков Telegram ~20 мс).
  Все времена в `words.json` — на таймлайне ВИДЕО.

## 3. Режиссура: монтажный план (`plan.py`)

Скопируй `scripts/template/` в рабочую папку и перепиши `plan.py`. Это единственный источник
времени для звука и картинки. Порядок мысли:

1. **Разбей речь на смысловые фразы** и для каждой реши: какой визуальный образ её несёт
   (не иллюстрация «в лоб», а метафора/интерфейс/цифра), какое слово главное, какой звук.
   Формат «бит-листа» и примеры — `references/creative-doctrine.md`.
2. **Хук (0–0.6 с)**: самая сильная фраза из ВСЕГО ролика крупным текстом с первого кадра
   («ОНИ ТОЧНО ТОП»), три удара под три слова. Первый кадр = обложка, он не может быть пустым.
3. **Сквозной мотив**: форма спикера (кружок → буква «O» в логотипе, глобус, печать, точка
   в финале). Мотив связывает сцены вместо переходов «ради переходов».
4. **Ритм цвета**: бумага / чернила / красный меняются на границах музыкальных секций, а не
   случайно. Дроп = красный фон + логотип. Стоп = чёрный.
5. **Темп-сетка, привязанная к речи** (подробно — `references/sound-design.md`):
   выбери слово-дроп (обычно второе упоминание бренда), поставь на него даунбит такта и
   подбери BPM так, чтобы финальное слово тоже легло на долю. Проверь, куда падают остальные
   ключевые слова; сдвиг до 1/16 норм.
6. **Сцены**: список `(start, end, scene, transition_in)`; сцена 0.4–3.5 с, смена образа минимум
   каждые ~2 с, внутри сцены — кинетика по словам. Переходы: `cut, iris, whip_left/right,
   zoom, slide_up, glitch, flash, slam, dissolve, cut_black`.
7. **SFX-лист**: на каждое визуальное событие — звук (whoosh на переход, stamp на печать,
   pop/card на появление, typing на печать текста, impact на дроп). Те же времена, что в сценах.

## 4. Музыка и звук (`score.py`)

Принципы (детали, формулы и уровни — `references/sound-design.md`):
- **Тональность из голоса**: медиана F0 спикера → тоника (у этого спикера 82 Гц = E2 → ми минор).
- **Аранжировка по драматургии речи**: intro (фильтр открывается к первому бренду) → verse →
  B-часть → **стоп** (tape-stop на «я точно рекомендую…») → **дроп** на бренде → breakdown на
  благодарности → build → финальный дроп → **тишина перед последним словом** → удар на нём.
- **Call & response**: аккорды/стабы звучат в полную силу только в паузах речи, под словами —
  тише и темнее. Перкуссия-«блипы» — только в паузах.
- **Речь играет музыку**: в breakdown ноты плака запускаются ударными словами спикера;
  «стеклянный» синт повторяет интонацию фразы (F0 → пентатоника, +3 октавы), тихо.
- **Звуковой логотип** бренда (2 ноты на упоминание, 4 на финал) — один и тот же мотив.
- **Сведение**: голос −16 LUFS; музыка калибруется автоматически так, чтобы во время речи
  голос был на **10 LU** громче по «телефонному» взвешиванию (ФВЧ 250 Гц — то, что играет
  динамик телефона) и ≥ 5 LU по полному спектру; дакинг −6 дБ широкополосно и ещё −4 дБ в
  0.6–4.5 кГц; полка −9.5 дБ ниже 130 Гц на шину музыки, чтобы громкость шла не из саба;
  мастер −14 LUFS, true peak ≤ −1 dBTP. Эхо-«бросок» на последнем слове.

## 5. Картинка (`render.py`)

- Холст 1080×1920, 30 fps. Безопасная зона Reels: ключевое содержимое по Y 220…1520,
  по X 72…1008 (низ закрывают подпись и кнопки).
- Используй атомы из шаблона: `speaker()` (круг с тенью и сдвинутым красным кольцом —
  «печать со сдвигом приводки»), `speaker_halftone()`, `slam_text()`, `kinetic()` (rise / drop /
  scale / jitter), `label()` (наклейки), `marker_underline()`, `seal()`, `rings_pulse()`,
  `icon_logo()` (логотип с живым кругом в «O»), `picto()`, `globe_lines()`, `info_bar()`.
- Виртуальная камера: медленный наезд в каждой сцене + бамп 1.2% на каждую бочку; тряска
  и хроматическая аберрация только на ударах из списка `IMPACTS`.
- Субтитры — только там, где графика НЕ несёт слова (иначе дублирование). Активное слово —
  в красной плашке.
- **Фоточувствительность**: не больше 3 полноэкранных вспышек в секунду; стробы на билдах —
  низкоконтрастные (5–7% непрозрачности).
- Шрифты с кириллицей (+казахские буквы): Oswald 700 (заголовки), Dela Gothic One (удары),
  Unbounded 900 (логотип), Playfair Display Italic (киккеры), JetBrains Mono (лейблы),
  Montserrat (субтитры). Shaped-текст Skia рисуется от верха строки — `gfx.draw_text`
  уже компенсирует асцендер.

## 6. Рендер и QA — не отдавай без этого

```bash
python3 $WORK/score.py $WORK/voice48k.wav $WORK/f0.npz $WORK/audio      # печатает LUFS / TP / баланс голос-музыка
python3 $SK/scripts/audio_qa.py $WORK/audio $WORK/words.json $WORK/audio/qa.png '{"DROP":27.68}'  # OK или WARN
python3 $WORK/render.py frames $WORK/stills 0.03 0.6 4.2 ...            # стоп-кадры каждой сцены
python3 $SK/scripts/contact.py $WORK/stills $WORK/sheet.png 6            # контакт-лист → посмотри глазами
python3 $WORK/render.py video $WORK/reel_master.mp4 $WORK/audio/mix.wav 4  # параллельный рендер (CRF 18)
python3 $SK/scripts/video_qa.py $WORK/reel_master.mp4 $WORK/qa 0.5      # сетка кадров + EBU R128 по файлу
ffmpeg -i $WORK/reel_master.mp4 -c:v libx264 -preset slow -crf 20 -maxrate 20M -bufsize 40M \
       -pix_fmt yuv420p -c:a copy -movflags +faststart $WORK/reel.mp4   # версия для отправки
```

Чек-лист перед отдачей:
- [ ] Первый кадр — читаемый хук; нет пустых/чёрных кадров, кроме задуманных.
- [ ] Ни один текст не вылезает за края и не заходит в нижние ~400 px.
- [ ] Каждое ключевое слово появляется на экране не позже, чем звучит (лучше на 1–2 кадра раньше).
- [ ] Голос над музыкой во время речи: ~10 LU «телефонно» и ≥ 5 LU полным спектром;
      мастер −14 LUFS ±0.5, TP ≤ −1 dBTP; моно-корреляция L/R > 0.5.
- [ ] Стоп и финальная тишина реально тихие; дроп совпадает с брендом до кадра.
- [ ] Имена/бренды/цифры совпадают с речью; спорные написания перечислены пользователю.

## 7. Что отдать

`reel.mp4` (H.264, yuv420p, AAC 256k/48k, +faststart), обложку (кадр хука), стемы
(voice/music/sfx), `plan.py` + `words.json` (чтобы перемонтировать за минуты), и короткий
отчёт: что сделано, где сомнения в расшифровке, что можно поменять одной строкой
(слово-дроп, BPM, палитра, сцены).
