# Иллюстрации: миры, сквозной предмет, живая карточка

Почти весь язык abat-reel держится на иллюстрациях: фраза спикера **доказывается предметом**, который
собирается на её словах. В стиле «Холст» эти предметы нарисованы как в скетчбуке — тушь + акварель, —
а не плоским вектором. Библиотека: `scripts/engine/illo.py`, слой в шаблоне: `render.py → draw_props`,
расписание: `plan.PROPS`.

## 1. Как выглядит предмет (рецепт `Sketch`)

Каждый предмет — набор контуров в «дизайн-единицах» и один вызов `render(px)` → `skia.Image`:

1. **Заливка-акварель** чуть мимо контура (`off`, 2–5 px — «приводка руки»), с прозрачностью 0.85–0.95.
2. **Пигмент у кромки**: размытая тёмная обводка внутри формы (засохший край акварели).
3. **Грануляция**: альфа-текстура зерна через `DstIn` — заливка дышит, как на бумаге.
4. **Линия тушью** с `DiscretePathEffect` (рука дрожит) и вторым тонким проходом со сдвигом
   (перо «дышит»). Минимальная толщина линии 2.4 px на выходе — иконки не рассыпаются.
5. Контуры, которые просвечивают сквозь полупрозрачную заливку (ноги под курткой, шея под головой,
   торс под рукавом), **вырезаются булевыми операциями** (`skia.Op … kDifference`) — иначе выглядит
   как рентген.

Палитра (`illo.PAL`): терракота, сланец, охра, шалфей, крафт, крем, кожа, бумага, тушь, красный, золото.
Та же, что у разливов холста — предметы и фон из одной коробки красок.

`with_rim(img)` — бумажная кромка (abat: «белый ободок»): силуэт, расширенный цветом бумаги. Нужна
иконкам у кружка и любому предмету поверх тёмного разлива. На чистом холсте предметам с «ногами»
вместо кромки — мягкая тень (`shadow=True`).

Готовые предметы: `figure` / `figure_one` / `duo` (безликие люди; руки `None|wave|point|hold|cheer`,
причёски `short|side`), `duo_on_pedestal`, `sign` (табличка с названием бренда — шрифтом, не логотипом),
`book_open` (пустая / исписанная), `book_closed` (+ сургучная печать), `cap`, `stairs`, `toolbox`, `wrench`,
`gear`, `magnet`, `chart`, `globe`, `pin`, `heart`, `magnifier`, `magnifier_duo`, `sparkle`.
Посмотреть все: `python3 scripts/illo_sheet.py out.png`. Новый предмет — функция на 10–25 строк
по тому же рецепту; добавь его в лист и посмотри глазами на холсте, крупно и в 150 px.

Никогда: портрет (у людей нет лиц — это «двое из агентства», не конкретные лица), чужие логотипы,
цифры/графики с выдуманными значениями (столбики без подписей — это «аналитика» вообще, не результат).

## 2. Как предмет живёт на экране (`plan.PROPS`)

```python
prop(t, out, key, w, x, y, anim="pop", anchor="center", states=[(t, key2)], hops=[(t, x, y)],
     rim=False, shadow=False, snd=("wood", {"note": 76}), rot=0)
```

| Поле | Смысл |
|---|---|
| `t` | слово, на которое предмет **приземляется** (для `drop` — момент касания, падение начинается за 0.22 с) |
| `anim` | `pop` (0.36 с, easeOutBack из 55%, лёгкий доворот) · `drop` (падение с ускорением + «шмяк») · `paint` (заливка слева направо мокрым фронтом, 0.55 с — для крупных: книга, лестница, глобус) · `rise` (снизу из размытия) |
| `states` | смена состояния на слове: кроссфейд 0.14 с + «пульс» 8% (машет рукой на своём имени, книга исписывается на «трафику», лупа находит дуэт на «подрядчик», иконка дуэта становится сердцем на «благодарен», на курс ставят печать на «работа») |
| `hops` | прыжки по точкам, каждый приземляется на своё слово (дуэт поднимается по ступеням на «очень / высокого / уровня / профессионалы») |
| `anchor="bottom"` | (x, y) — точка между ступнями; позиция считается по нижнему закрашенному ряду картинки |
| `out` | уход: 0.2 с прозрачность + сжатие 6%; уходит вместе со своим миром |

Всё живое: лёгкое покачивание (2.5 px, 0.45 Гц) и наклон (0.7°), а в мире весь слой предметов медленно
наезжает 1.00 → 1.04 (`plan.WORLDS`) — камера никогда не стоит.

## 3. Мир и лицо — чередование (abat + motion-canvas-pro)

- **Лицо** (кружок крупно, ≥ 50% речи): кластер под кружком — строка serif + главное слово кистью +
  **иконка ~150–190 px** справа (в идеале миниатюра сквозного предмета) + **отметка рукой**
  (`under` — подчеркнуть слово, `ring` — обвести, `arrow` — показать путь). Иконка меняет состояние на
  слове (дуэт → сердце).
- **Мир** (кружок сжимается в **живую карточку** в углу, `L["card"]`, говорит синхронно): посреди холста
  собирается ОДИН предмет на словах. Мир открывается **подписью-меткой** вверху слева (`kind="label"`,
  курсив, ≤ 600 px — она не заезжает под карточку), строка под предметом, отметка рукой, вердикт
  (печать, булавка, пьедестал). Сжатие/возврат кружка = шов; под ним — мягкий «воздух».
- **Ритм**: новое событие каждые 0.4–0.8 с на своём слове; новый бит ~3 с; шов каждые 4–6 с; дыра без
  события > 1.5 с во время речи = дефект. Проверка: `scripts/rhythm_qa.py`.
- **Сквозной предмет** возвращается 3+ раз в новых состояниях и как иконка. В ICON это дуэт:
  знакомство под табличкой → по бокам книги курса → вверх по лестнице → в лупе → рядом со спикером
  («они у меня подрядчики») → иконка, ставшая сердцем → под табличкой, к ним ведёт стрелка → на пьедестале
  на «топ.».
- **Размер**: один главный предмет мира 380–760 px; мелкие 100–210 px. Предметы не перекрывают текст
  и голову; карточка спикера (x 715–985, y 195–465) — запретная зона.
