# Звук: процедурная партитура вокруг речи

Музыка генерируется кодом (`scripts/engine/`), без сэмплов и стоков: numpy + numba.
Поэтому её можно подогнать под речь до сэмпла — это главное преимущество.

## 1. Тональность из голоса

`analyze_voice.py` считает F0 (YIN) и строит гистограмму высот. Медиана F0 = тоника.
Пример: медиана 82 Гц = E2 → ми минор (Em9 – Cmaj9 – G6/9 – D6/9 – Am9 – B7sus4).
Мажор/минор: по корреляции профилей Крумхансла с гистограммой голоса + по настроению
(отзыв/благодарность → минор с мажорными подменами в breakdown; оффер → мажор).

Перепроверь F0 вторым методом (кепстр) — у низких голосов YIN ошибается на октаву.

## 2. Темп-сетка, привязанная к речи

```
BAR1 = t_drop - (n_drop - 1) * 4 * 60/BPM
```
1. Слово-дроп (второе упоминание бренда, «рекомендую», ключевой оффер) = даунбит такта n_drop.
2. Перебери BPM 110–130: финальное слово тоже должно лечь на долю (|ошибка| < 25 мс).
   В шаблоне: дроп 27.68 с (бар 15) и «топ» 41.14 с (бар 22) → 124.8 BPM, и тогда
   бар 1 = 0.757 с = «привет», первый «ICON» = 4-я доля бара 3, «поэтому» = бар 17,
   «очень высококачественная» = бар 19. Совпадения — признак правильной сетки.
3. Если глобальный темп не сходится, делай секции со своим темпом (±4%) и прячь стыки
   за стопами, райзерами и breakdown.

## 3. Аранжировка = драматургия речи

| Секция | Что звучит | Зачем |
|---|---|---|
| hook (до речи) | 3 удара под 3 слова хука, реверс-свелл в бар 1 | внимание с первого кадра |
| intro | бочка, тихие хэты, пэд; ФНЧ 650 Гц → 3.2 кГц | «вход», не мешаем знакомству |
| первый бренд | фильтр мгновенно открывается + звуковой логотип | бренд = событие |
| verse | house/garage грув, саб-бас, стабы в паузах | движение |
| level | бочка в half-time, арпеджио-шкала, удар на итоговом слове | «уровень растёт» |
| B-часть | + reese-бас, перкуссия-блипы в паузах, открытые хэты | энергия перед стопом |
| **стоп** | tape-stop на «я точно…», тишина, печать+саб на «рекомендую», дробь, райзер | главная фраза в тишине |
| **дроп** | всё + импакт + логотип на бренде | кульминация |
| breakdown | пэд, мягкая бочка, плак от слов спикера, синт-интонация | эмоция, «спасибо» |
| build | бочка на каждую долю, дробь 8→16→32, ФВЧ поднимается, райзер | разгон |
| финальный дроп | максимальная энергия | призыв |
| **тишина** | всё обрезано за 1 долю до последнего слова, реверс-вдох | панчлайн в вакууме |
| финал | удар + аккорд + саб + логотип 4 ноты + эхо последнего слова | точка |

## 4. Речь как часть музыки

- **Call & response**: каждый стаб проверяет `speech_at(t, t+0.16)`: в паузе — громко и ярко
  (gain 0.42, cutoff 4.2 кГц), под словом — тихо и темно (0.14, 2.4 кГц).
- **Слова играют ноты**: в breakdown список ударных слов (`PLUCK_WORDS`) запускает плак+колокол
  по мелодии из аккорда.
- **Удвоение интонации**: F0 фразы ×8 (3 октавы), квантование в пентатонику, глайд 30 мс,
  огибающая = озвученность. Громкость 0.12–0.2 до дакинга — едва слышно, но «музыкально».
- **Звуковой логотип**: B4→E5 на каждое упоминание бренда, B4-E5-F#5-B5 в финале
  (колокол FM + плак, пинг-понг дилей 3/16).
- **Эхо-бросок** последнего слова (дилей 3/16, fb 0.45, реверб) — только где после него тишина.

## 5. Саунд-дизайн на картинку

Каждое визуальное событие в `plan.SFX` и звучит ровно тогда, когда видно. Для стиля «Холст»
звуки — рукотворные: `brush` (кисть по холсту: дыхание шума в полосе 1.7–2.6 кГц, зерно
щетины, редкий треск, панорама по направлению мазка; длительность = длительности мазка/написания),
`brush_big` (кисть + мягкий саб — «подпись» на главном слове), `air` (вдох воздуха на финале),
`bell` (колокольчик на имена), звуковой логотип, `impact` только на дропах, `tape_stop`, `reverse_swell`.
Перкуссия-«блипы» — на октаву ниже и мягче (деревянные, не цифровые).
Не используй в «Холсте»: клики клавиатуры/мыши, UI-попы, глитч, штампы, свисты-whoosh на каждый переход.

## 6. Голос

`mix.process_voice`: ФВЧ 65 Гц → −2.5 дБ @300 Гц → +3 дБ @3.4 кГц → +2 дБ полка 9.5 кГц →
мягкий экспандер (−9 дБ max, режет комнату между словами) → де-эссер 5.5–10 кГц →
компрессор 3.2:1 → быстрый 6:1 → нормализация −16 LUFS.

## 7. Сведение и мастер (цифры, которые проверяем)

| Параметр | Цель |
|---|---|
| Голос | −16 LUFS integrated |
| Голос над музыкой во время речи, «телефонно» (ФВЧ 250 Гц, по маске слов) | **10 LU** — авто-калибровка в `score.py` (`VOICE_OVER_MUSIC_LU`) |
| То же полным спектром (K-weighted) | ≥ 5 LU (иначе саб давит голос в наушниках) |
| Наклон шины музыки | полка −9.5 дБ @130 Гц, −2.5 дБ @11 кГц |
| Дакинг музыки под голосом | −6 дБ широкополосно, ещё −4 дБ в 0.6–4.5 кГц |
| Пампинг от бочки (бас, пэды, стабы) | −8.5 дБ, восстановление 240 мс |
| Мастер | −14 LUFS integrated, true peak ≤ −1.0 dBTP |
| Стоп и финальная тишина | реально ноль в музыке (проверяй на графике `audio_qa.py`) |

Почему «телефонное» взвешивание: Reels слушают в основном с динамика телефона, который не
играет ниже ~200 Гц. Если калибровать по полному спектру, громкость музыки «съедает» саб, и на
телефоне музыка под речью исчезает (было измерено: 7 LU полным спектром = 18 LU на телефоне).
Если голос «тонет» — поднимай `VOICE_OVER_MUSIC_LU` до 11–12; если музыка «не слышна» — 8–9.
Басу нужны гармоники (reese на октаву выше, сатурация), бочке — щелчок.
