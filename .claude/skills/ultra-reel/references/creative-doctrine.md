# Креативная доктрина ULTRA REEL

Четыре школы в одной:

| Школа | Что берём |
|---|---|
| **kinetic-speaker** | Слово появляется ровно тогда, когда звучит. Буквы поднимаются / падают / шлёпаются по одной (stagger 12–50 мс). Главное слово фразы — другой шрифт, другой цвет, удар. |
| **visual-essay** | Не «субтитры поверх лица», а визуальная мысль: бумажный коллаж, полутон, печати, наклейки, маркер, UI-карточки, большие цифры. Камера не стоит: медленный наезд + бампы на бочку. |
| **triplex** | Три материала в одном кадре: типографика несёт слова, объект (UI-карточка, глобус, печать, логотип) несёт смысл, спикер несёт доверие. Ни один не дублирует другой. |
| **abat** (отзыв/эксперт) | Доверие = лицо спикера в кадре почти всё время (кружок, PiP-кружок, круг-«O» в логотипе), его имя и компания наклейками в первые 3 секунды, бренд-получатель — на дропе и в финале. |

## Бит-лист: как думать о каждой фразе

Для каждой смысловой фразы записываем 5 полей. Пример из шаблона (отзыв ICON):

| Время | Речь | Образ | Кинетика | Звук |
|---|---|---|---|---|

| 0.57–3.2 | «Всем привет, это Антон Петраченков, компания ConvertMonster» | Ирис из красной «О» в кружок спикера, наклейки имени и компании | наклейки на пружине | swish на каждую наклейку, грув стартует фильтрованным |
| 4.36 | «поблагодарить» | Слово во всю ширину | slam 1.6→1 | thud + whoosh |
| 4.84 | «двух маркетологов» | Гигантская красная «2» | rise по буквам | stamp |
| 6.04 | «ICON» | Красный фон, «IC◯N», в «O» живой кружок | пружина + кольца | звуковой логотип (2 ноты) + фильтр открывается |
| 6.9 / 8.7 | «Абубакир и Еркебулан» | Две ID-карточки, линии от кружка к карточкам | pop + галочка | card-pop + колокольчики (E5, B5) |

| 14.6–16.6 | «очень высокого уровня профессионалы» | Чёрный фон, спикер в полутоне, шкала LVL до MAX | 10 сегментов = 10 нот арпеджио | арпеджио вверх, удар на «профессионалы» |

| 22.8–25.2 | «зарубежными инструментами… в СНГ» | Кружок спикера = глобус (меридианы), чипы вокруг, пин «СНГ» | вращение | pin + ding |

| 31.5–35.4 | «спасибо… благодарен» | Тёплая бумага, «СПАСИБО» по буквам, звёздочки на ударных словах | медленный дрейф | breakdown: пэд, плак от слов спикера, синт повторяет интонацию |
| 35.4–37.3 | «высококачественная работа» | Печать «КАЧЕСТВО» крутится | наезд ускоряется | build: дробь, райзер |
| 37.3–40.65 | «…идите к ним» | Смена фона на каждую 2-ю долю: красный/бумага/чёрный/красный, стрелка → логотип | слэмы | финальный дроп |
| 40.65–41.14 | «они точно» | Чёрный, тишина | слово за словом | **полная тишина** + реверс-вдох |
| 41.14 | «топ» | «Т◯П» на красном, кружок в «О» | слэм 2.2→1 | финальный удар + логотип + эхо «топ… топ…» |
| 42.4–44.6 | — | Энд-карта: «IC◯N» → «O» заливается красным | — | хвост аккорда |

## Правила, которые делают «топ», а не «нормально»

1. **Каждое визуальное событие стоит на слове или на доле.** Не «где-то в середине сцены».
   Текст появляется на 1–2 кадра раньше слова (глаз опережает ухо).
2. **Одна мысль — один главный объект.** Фон + спикер + 1 объект + 1–2 текстовых уровня.
3. **Масштабный контраст**: в каждой сцене есть что-то ОЧЕНЬ большое (слово/цифра на всю ширину)
   и что-то мелкое (лейбл моно-шрифтом). Средних размеров мало.
4. **Цвет — драматургия**: бумага = рассказ, чёрный = напряжение/стоп, красный = бренд/дроп.
5. **Повтор мотива** вместо случайных эффектов: круг спикера повторяется как «O» в бренде,
   глобус, печать, точка в финале. Хук в начале = последнее слово в финале (кольцевая композиция).
6. **Переход несёт смысл**: ирис из красной «О» хука → кружок; zoom через сцену = «углубляемся»;
   whip = «следующий пункт»; glitch = смена регистра (на чёрный); cut_black = стоп.
7. **Субтитры не дублируют графику.** Если слово уже большое на экране — субтитров нет.
8. **Безопасные зоны**: Y 220…1520 для смысла. Сверху — «бегущая шапка» (формат + кто → кому).
9. **Не выдумывать**: только сказанное или честный пересказ. Никаких фейковых звёзд,
   цифр «+300%», «основатель», если этого не сказали.
10. **Финальная плашка** зацикливается с началом: чистый логотип + что делает компания
    (словами спикера) + «отзыв: Имя, Компания».

## Палитра и шрифты шаблона

- Бумага `#EEE7DA`, крем `#F4EBDC`, чернила `#141414`, сигнальный красный `#E3342F`, серый `#8B8478`.
- Фактура бумаги (шум + волокна), зерно 7σ на каждый кадр, виньетка 16%.
- Oswald 700 — заголовки; Dela Gothic One — удары и цифры; Unbounded 900 — логотип;
  Playfair Display 700 Italic — рукописные киккеры («лично», «ребят,»); JetBrains Mono 800 —
  лейблы и UI; Montserrat 900 — субтитры.

Под другой бренд меняй только палитру/шрифты/логотип-функцию — сцены и тайминги переносятся.

## Библиотека сцен шаблона (render.py)

| Сцена | Когда использовать |
|---|---|
| `hook` | Первые 0.3–0.6 с: цитата-панчлайн в 2–3 строки, слэмы |
| `intro` | Кружок спикера + наклейки имени/компании |
| `thank`, `helped` | Ключевой глагол во всю ширину над кружком |
| `two` | Число из речи гигантской цифрой |
| `icon1`, `drop1` | Бренд с кружком в «O», красный фон, кольца |
| `names` | Люди/участники: ID-карточки с инициалами и линиями связи |
| `course` | Продукт/процесс: UI-карточка с модулями, галочками, прогрессом |
| `level` | Уровень/качество: полутон + шкала |
| `ifyou` | Прямое обращение к зрителю: крупный план лица |
| `search` | «Если вам нужен X»: строка поиска с печатью по буквам |
| `tools` | Перечисление: сетка плиток-пиктограмм, одна плитка — спикер |
| `globe` | География/рынок: кружок-глобус, пин |
| `stop` | Главная рекомендация: чёрный, печать, наезд, тишина в музыке |
| `contractors` | Личное подтверждение: печать «ПРОВЕРЕНО ЛИЧНО», сетка-ритм |
| `thanks` | Благодарность/эмоция: тёплый свет, медленно, звёздочки на словах |
| `quality` | Оценка работы: крутящаяся печать |
| `final` | Призыв: смена фонов по долям, стрелка к логотипу |
| `pause`, `top` | Пауза перед последним словом и удар-панчлайн |
| `logo` | Энд-карта |
